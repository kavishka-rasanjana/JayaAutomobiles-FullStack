## ✨ Key Features

### 🏢 Client Side (Frontend)
- **Modern Dark UI:** A premium, glassmorphism-inspired interface tailored for the automobile industry.
- **Search Functionality:** Real-time filtering of vehicles by brand or model.
- **Responsive Design:** Fully optimized for Desktop, Tablet, and Mobile devices.
- **Dynamic Routing:** Seamless navigation using React Router.

### ⚙️ Admin Side (Backend)
- **JWT Authentication:** Secure Login/Register system for Admins.
- **Inventory Management:** Add, Update, and Remove vehicles with ease.
- **Data Validation:** Strict input validation for data integrity.
- **MongoDB Integration:** High-performance NoSQL database implementation.

---

## 🛠️ Tech Stack

### **Frontend**
- **Framework:** React.js (v18)
- **Styling:** React Bootstrap & Custom CSS (Glassmorphism)
- **HTTP Client:** Axios
- **Routing:** React Router DOM

### **Backend**
- **Framework:** ASP.NET Core Web API (.NET 8)
- **Database:** MongoDB Atlas (Cloud)
- **Authentication:** JWT (JSON Web Tokens)
- **Architecture:** Controller-Service Pattern
